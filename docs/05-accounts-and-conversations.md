项目位置：`/Users/susu/Desktop/research-workbench`。入口：http://localhost:3000。

## 本次需求与交付

| 需求 | 已实现行为 |
| --- | --- |
| 简单会话 | 普通问答独立于研究图，支持上下文、发送状态、失败提示和历史持久化 |
| 新增会话 | 创建空白会话、标题自动命名、会话列表和历史切换 |
| 不同账号 | 注册、登录、退出、会话有效期与归属隔离 |
| 管理员查看记录 | 账号统计、筛选、搜索、分页、聊天详情和研究详情只读审阅 |

首个注册账号为管理员，后续为普通用户。客户端不能自行指定管理员角色。原有无归属的本地项目在首次注册时迁给管理员。没有预设账号或默认密码。

## 系统结构

前端使用账号外壳，包含普通会话、深度研究和管理员三个入口。研究组件保留原有 LangGraph 流程、项目资料、证据和导出能力。

FastAPI 中间件先验证本机来源，再验证 Session。普通资源接口按所有者授权；管理员接口按角色授权，并通过独立只读路由查询不同用户的数据。管理员通过普通接口仍只能操作自己的记录。

会话生成流程：验证归属 → 事务保存用户消息与待生成助手消息 → 组装本会话上下文 → 请求模型 → 保存成功或失败结果。请求标识防止重试造成重复消息，数据库约束及事务限制每个会话只有一个待生成回复。重启时将遗留待生成消息标记为失败。

## 数据模型

| 表 / 字段 | 用途 |
| --- | --- |
| users | 用户标识、用户名、显示名称、密码哈希与角色 |
| sessions | Token 哈希、账号与过期时间 |
| login_attempts | 登录失败次数及短时限流 |
| projects.owner_id | 已有研究项目的归属；任务、资料和证据沿项目授权 |
| conversations | 所有者、标题和创建 / 更新时间 |
| chat_messages | 用户 / 助手、正文、状态、模型、Token 和请求标识 |
| admin_audit | 管理员、读取动作、目标与时间 |

密码使用独立随机盐的 scrypt。Cookie 为 HttpOnly、SameSite=Strict，有效期七天；退出撤销数据库 Session。本机 HTTP 开发配置尚未启用 Secure Cookie。

## 验证与边界

后端测试覆盖会话幂等、并发发送、跨账号资源拒绝、管理员权限、审计、历史迁移、会话和登录重启恢复。多轮模型接口测试使用模拟 HTTP 响应，没有调用真实供应商模型。前端 TypeScript 检查和生产构建以当前仓库脚本为准。

本轮浏览器自动化接口连续超时，未完成新增页面的可视交互验收。已更新 Playwright 流程；运行前需要已有本地测试账号的 `E2E_USERNAME` 和 `E2E_PASSWORD`。

当前默认演示模式，普通会话明确显示模拟回复。Live 普通会话只需要模型服务配置，深度研究还需要 Tavily。上下文限制为最近 30 条已完成消息及 30000 字符。普通会话已支持 POST SSE 逐 Token 流式响应（`llm.stream_complete`），增量写入消息；研究任务的进度仍是持久化事件 SSE，另加轮询。

当前仍为本机单进程工作台，尚未实现生产认证服务、密码重置、多 Worker 调度、账号角色管理和管理员审阅全文检索。公网部署需要独立配置 HTTPS、Secure Cookie、注册与会话策略及任务调度。
